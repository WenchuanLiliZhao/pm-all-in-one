# `.agents/skills/`

| Dir | Role |
| --- | --- |
| `core/` | Create-time product seeds. **Do not create, edit, rename, or delete** anything under here. |
| `custom/` | Library / user conventions. Put new skills here (see `pm-create-skill`). |

If a core skill is wrong for this library, leave it alone and override with a skill under `custom/`.
