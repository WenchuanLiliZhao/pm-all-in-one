# local-pm workspace

This folder is a **local-pm** project library. Structural law lives in:

→ `.pm/agent.md`  (read this before creating or moving anything)

Hard rules (summary):

- Never invent or rename nanoid directory ids; create via the app or CLI.
- Do not hand-edit `parentId` / `level` / `created` / `updated` / `createdBy`.
- Project description ≠ epic ≠ wiki — see skill `pm-content-placement` under `.agents/skills/core/`.
- Agent Skills: create-time seeds in `.agents/skills/core/`; your conventions in `.agents/skills/custom/` (see `pm-create-skill`). Do not edit this file or `.pm/agent.md` to add them.
- Live `@issue-…` / `@wiki-…` / `@member-…` / `@handoff-…` locators in bodies: bare text, never backticks.
